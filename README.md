# Subtask 1: Morse Code Overview and Research

## 1. Overview
Morse code is a method used in telecommunication to encode text characters as standardized sequences of two different signal durations, called dots and dashes. It was designed to allow transmission of textual information across audio tones, visual lights, or electrical pulses.

## 2. Historical Context
Developed in the early 1830s by Samuel Morse and Alfred Vail for the electric telegraph, Morse code revolutionized long-distance communication. It was later adapted internationally in 1851 to form the International Morse Code standard, which became crucial for maritime, military, and aviation communication.

## 3. How the Morse Code System Works
- **Dot (`.`):** Represents the short signal unit (1 unit duration).
- **Dash (`-`):** Represents the long signal unit (3 units duration).
- **Intra-character space:** Space between dots/dashes within a letter is 1 unit.
- **Letter space:** Space between letters in a word is 3 units.
- **Word space:** Space between words is 7 units.
